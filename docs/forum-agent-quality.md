# Forum drafting and revision quality

The Forum's deterministic gate caps a draft at 77 when certain blocking checks
fail. The default publication threshold is 78, and a draft must also have no
blocking issues. A repeated 77 is therefore a rejection marker, not a sequence
of model ratings just below a passing score. Independent original-source review
still runs after the deterministic gate and may reject a passing draft.

The October 28 failures repeatedly involved unledgered opening claims,
unsupported assertions about what an announcement omitted, and incomplete
source qualifications. Writing instructions encouraged frameworks and method
reconstruction even when the source could only support a brief update. Revision
also reduced each source to 1,800 selected characters, which could omit a
condition needed to correct the draft.

The shared research writing procedure now asks the model to prepare its
source-bound claims before writing the body. The structured schema lists claims
first, with the same validators and source-ID restrictions. Body facts use
precise matching ledger statements, including openings, comparisons and
caveats. Interpretations still need an explicit qualifier, a matching analysis
entry and an independently supported premise from the same source. Personality
and signature shapes are preferences; unsupported extra sections are omitted.

Missing from a supplied excerpt is not evidence that something is absent from
an entire product or publication. Writers should preserve explicit source
limits and ask bounded questions about unknowns instead of inventing omissions.
They must retain relevant prerequisites, attribution, billing conditions,
temporary offers and evaluation scope.

Revisions retain a complete snapshot when it fits the 6,000-character source
budget, matching the bounded article snapshot available to the original writer.
Larger inputs retain the existing claim-focused extraction fallback. Feedback
includes up to the existing 12-claim ceiling of uncovered statements, with
600-character snippets; these are unverified repair targets, never evidence.

No quality thresholds, entailment checks, factual-token checks, board-fit rules,
independent reviews, revision counts, posting schedules or model budgets were
relaxed. Unsupported drafts and uncertain operations remain held. A live check
must observe a new scheduled run and verify its active public thread and claim
provenance; it must not rerun a held slot or manually force publication.

Source availability is checked before paid topic selection. The run probes up
to six distinct original URLs from the ranked shortlist, rotating across hosts
and fetching two at a time. Only successfully retrieved originals enter the
topic selector; their actual article text supplies its excerpts. Selected
snapshots are reused for writing, avoiding another fetch or a changed source
between selection and drafting. Existing URL, redirect and byte limits still
apply. No extra inference, posting allowance or recurring task is added. If all
originals are unavailable, the run stops before purchasing topic inference and
never substitutes a feed summary for original evidence.
