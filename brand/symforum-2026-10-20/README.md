# SYMBaiEX Forum — Signal Moth identity

The existing website Signal Moth sprite is the identity reference. Artwork was
created with the built-in image-generation tool, then composed, scaled to 76%,
saved and exported in Apple's Icon Composer. Glass effects are disabled on the
foreground to keep the CRT face and circuit-wing details crisp.

## Deliverables

- `SYMBaiEX-Forum.icon/`: editable native Icon Composer document and foreground.
- `symforum-icon-1024.png`: native Icon Composer export, website/app icon master.
- `x-avatar-400.png`: upload-ready X profile image. Keep the whole square; X crops it to a circle.
- `x-banner-1500x500.png`: upload-ready X header; exact title `SYMBaiEX Forum`.
- `x-banner-source.png`: higher-resolution generated banner source.
- `signal-moth-icon-foreground.png`: transparent generated mascot source.

The avatar and banner have not been uploaded to an X account. Website icon
derivatives live in `public/images/brand/`; legacy ICO and Apple touch icons are
also replaced, with metadata cache-busting for returning browsers.

## Generation prompts

### Mascot foreground

Use case: logo-brand. Create a production-ready transparent mascot foreground
layer for a website/app icon and X avatar for SYMBaiEX Forum. Reference image is
the existing Signal Moth mascot; preserve its identity: off-white chunky CRT
monitor face with black screen and two luminous pale yellow vertical eyes, two
long segmented antennae, small off-white robot body, asymmetrical black moth
wings with cyan and magenta circuit-like markings and delicate pale outline.
Refine into clean sharp deliberate pixel-informed geometric illustration, not
blurry enlarged pixel art, not generic robot. Slight friendly three-quarter pose
like the reference, wings readable as a single strong silhouette, face prominent.
No text or typography. 1024x1024 square composition, mascot centered within central
78% canvas with generous transparent margins so antennae and wings are uncut.
Transparent background genuinely alpha, no tile, no border, no cast shadow, no
checkerboard. Retain retro computer/moth charm, extremely clear at small sizes.

### X header

Use case: ads-marketing. Create a finished X/Twitter profile HEADER BANNER for
SYMBaiEX Forum. Ultra-wide 3:1 image, target 1500x500 pixels. Use supplied Signal
Moth icon artwork as mascot identity reference, preserve its CRT face, two yellow
eyes, off-white body, cyan antennae and magenta/cyan circuit wings exactly.
Premium restrained old-web community brand: near-black/charcoal background,
crisp off-white typography, small precise hot-magenta and icy-cyan accents
matching the mascot, subtle sparse pixel/circuit details. Not a neon cyberpunk
landscape, no gradients everywhere, no floating UI cards. Layout: keep bottom-left
300x160 zone quiet for X avatar overlap. Mascot appears on right third, medium
size with room around it. Main title left-of-center in the central safe band,
exact text 'SYMBaiEX Forum' in a confident clean technical sans-serif, excellent
typography and no misspellings; smaller line below 'forum.symbaiex.com'. Text must
remain away from top and bottom 65px cropping zones and right/left edges. A
coherent real community identity, balanced negative space, polished print-sharp
graphic design. No extra slogans, no other words, no watermark, no platform logo.
Output the complete banner artwork edge to edge, not a mockup, no rounded corners.
